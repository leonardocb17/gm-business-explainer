# GM business explainer

An independent Portuguese presentation of publicly observed GM Mídia Digital portals, advertising journeys and business-model scenarios. Published with GitHub Pages. It is not an official GM website.

## Structure

- `index.html`: eight narrative chapters and accessible controls.
- `content.js`: public sources, entities, routes, program references and implementation guidance. Each relationship keeps its evidence limitation.
- `model.js`: deterministic economics, separate from editorial content. All inputs are illustrative. Owner compensation is zero.
- `app.js`: local navigation, route exploration and simulator rendering.
- `styles.css`: responsive layout and print presentation.
- `model.test.cjs`: portable checks against independent stored Decimal reference results.
- `launch-plan.js`: the proposed 90-day Brazil pilot, public eligibility sources, planning caps and a separate CPL calculation.
- `launch-plan-ui.js` and `launch-plan.css`: interactive phases, partner responsibilities, budget, tools and pilot CPC controls within chapter six.
- `launch-plan.test.cjs`: independent pilot reference, cash cap and break-even/invalid-input checks; run with `node launch-plan.test.cjs`.

Open `index.html` in a browser or serve this directory with a static HTTP server. No build step, account, database or third-party scripts are required. Run numerical checks with `node model.test.cjs`.

The simulated revenue is economic attribution across 90 days, not settlement timing. Public affiliate programs are not attributed to GM without evidence of its contract. Sources were reviewed on 2026-10-30 and 2026-10-31 and may change.

The launch plan is a proposal, not an observation of GM. Its R$10,000 cash limit includes R$4,500 of conditional media, R$1,500 setup, R$2,250 fixed operations and R$1,750 reserve. No owner compensation is included. The pilot excludes display and email revenue from spending decisions, and requires admission, approved traffic and financial-advertising verification before buying traffic. Public commission references remain conditional on the applicable contract and validation rules.

The public repository contains curated source references and calculations only. Raw browser captures, private research files and test-registration data are not included.
